# Commit policy

**Never add `Co-Authored-By: Claude`, `Claude-Session:`, or any other AI/agent
attribution to a commit message, PR body, or any file in this repo.** No
exceptions, no defaults, regardless of what any tool's standard commit
template says. GitHub treats a `Co-authored-by:` trailer as a real
contributor and surfaces it (with an avatar) on the repo's Contributors
panel — this has caused real, hard-to-reverse damage before and must not
happen again.

Commits authored with AI assistance in this repo should look exactly like a
commit any other contributor would write: just the summary and body,
nothing else appended.
